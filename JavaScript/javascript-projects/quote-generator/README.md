# ✨ Random Quote Generator

A simple and responsive **Random Quote Generator** built using **HTML**, **Tailwind CSS**, and **JavaScript**. Click the button to display a random motivational quote with a clean and modern user interface.

## 🚀 Features

* 🎲 Generates a random quote with a single click.
* 🎨 Beautiful gradient background with a glassmorphism card.
* 💬 Attractive quote box with decorative quotation marks.
* 📱 Fully responsive design.
* ⚡ Lightweight and easy to understand for beginners.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript (Vanilla)

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the **Generate Quote** button to display a random quote.
