# 🚀 Responsive Agency Landing Page

A modern and fully responsive landing page built using **HTML** and **Tailwind CSS**. This project focuses on creating a clean, engaging user interface with responsive layouts, interactive hover effects, and modern design principles.

---

## 📸 Project Preview

![Responsive Agency Landing Page](preview.png)

---

## ✨ Features

- 📱 Fully Responsive Design (Mobile, Tablet & Desktop)
- 🎨 Modern UI built with Tailwind CSS
- 🧭 Responsive Navigation Bar
- 🌟 Interactive Hover Effects
- ⚡ Smooth Transitions & Animations
- 📐 Flexbox & CSS Grid Layout
- 🖼️ Responsive Image Placement
- 🎯 Call-to-Action Buttons
- 🎭 Custom Text Shadow Effects
- 💼 Professional Marketing Agency Landing Page Design

---

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Font Awesome

---

## 📚 Tailwind Concepts Used

- Responsive Breakpoints (`sm:`, `md:`, `lg:`)
- Flexbox Utilities
- Grid Layout
- Custom Hover Effects
- Transition & Animation Utilities
- Responsive Width & Height
- Rounded Corners
- Shadow & Text Shadow Utilities
- Background & Text Colors
- Spacing Utilities (`margin`, `padding`, `gap`)
- Positioning (`relative`, `absolute`)
